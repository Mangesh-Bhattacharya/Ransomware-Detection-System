# 🔒 Security Policy

## 📌 Supported Versions
The following table outlines the versions currently supported with security updates:

| Version | Supported |
|---------|------------|
| 1.0.x   | ✅ Yes |
| < 1.0   | ❌ No |

## 🚨 Reporting a Vulnerability
If you discover any security vulnerabilities, please follow these steps:

1. **Do not disclose publicly** – Instead, report it privately to the maintainers.
2. **Contact us via email** – Send a detailed report to `security@gh-bhattacharya.com`.
3. **Provide a detailed description** – Include steps to reproduce, potential impacts, and any mitigation suggestions.
4. **Wait for a response** – We will acknowledge the report within 48 hours and work on a fix.

## 🛡️ Security Best Practices
To ensure the security of your system while using this project:
- Keep your dependencies updated by running `pip install --upgrade -r requirements.txt`.
- Run the tool in a controlled environment to avoid unintended disruptions.
- Regularly check for updates and patches.

## ❗ Disclaimer
This tool is for **educational and research purposes only**. It is **not a replacement** for professional cybersecurity solutions. Use it responsibly and in compliance with all applicable laws.
